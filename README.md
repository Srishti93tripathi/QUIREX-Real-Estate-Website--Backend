Quirex is a full-stack Real Estate Property Discovery Platform designed to simplify property search, listing, and management. 
The platform enables users to explore properties efficiently while providing admins with robust tools to manage listings and users.

🚀 Features

👤 User Features

>>User authentication (Sign up / Login)

>>Browse real estate properties

>>Search and filter properties by location, price, and type

>>View detailed property information

>>Contact property owners or agents

🛠️ Admin Features

>>Admin authentication

>>Add, update, and delete property listings

>>Manage users and properties

>>Secure admin-only routes

⚙️ Backend Capabilities

>>RESTful API architecture

>>Secure authentication using JWT

>>Image upload support

>>Role-based access control

>>Scalable database design
